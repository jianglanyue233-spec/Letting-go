# Letting Go / 放开我的手

Interactive narrative web-game prototype about growing up through one gesture: holding and letting go.

## Play
Hold the mouse / touch the screen / hold Space to take a hand. When the moment comes, release to move forward.

## Chapters
1. Kindergarten — Age 5
2. Leaving Home — Age 18
3. The Stage — Age 23
4. My Own Work — Age 29
5. Home Again — years later

The web build lives in `index.html` and can be served directly with GitHub Pages.
